A Unified Slicer I'm Building Using Claude. Combines features of all sorts of slicers in order to have an all-in-one hub for wireless 3D printing. Connects to Elegoo, Bambu Lab, and Creality printers using their cloud services instead of a LAN connection. Log into multiple accounts and seamlessly switch between printer brands all inside this application.
